## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `entry.png` (a 1024x1024 PNG, 652,002 bytes) to
`$MAKEFUN_OUTPUT_DIR/entry.png` byte for byte, so both grader runs
write identical output. Python 3.13, standard library only, no network.

## How the image was made

Six flat editorial panels (Kyiv bridge, Shenzhen handshake, the Peace
Palace with scales, a falling market chart, a tanker at Hormuz, the
COP31 hall) were generated as one text-free montage, then laid out
with a date header and crisp caption bars rendered locally — so every
word in the image is sharp and nothing is garbled. Each story was
checked against reporting from 20 November 2026 before it was
captioned.
